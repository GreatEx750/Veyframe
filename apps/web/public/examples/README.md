# Studio examples

These bundled Northstar Analytics examples are 20-second, 2560 × 1440 MP4s with
AAC narration and matching posters. They are format samples, not saved user projects.
Full Presentation Demo generation still uses its fixed two-minute schedule.

- **Product:** retained video track from the existing Northstar export, with Google
  Gemini spoken narration replacing the verification fixture's audio tones.
- **Presentation:** two ten-second native-aperture browser recordings composed with
  the authored product-in-action and context-split templates. Script/copy were
  schema-validated through Google ADK/Gemini; narration used Gemini TTS. Mouse
  movement, click feedback, fitted copy, and word-highlighted captions use the
  application capture and rendering components.

Northstar is a fictional example app. Its locally observed controls ground the
presentation; these samples make no claim of external Parallel research.

The files are public, contain no session credentials, and ship with the web app's
existing public-directory packaging. Previewing them requires no generation call.
Asset integrity is checked by `scripts/studio-examples.test.mjs`.
